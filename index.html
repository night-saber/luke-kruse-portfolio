    About

    I'm Luke — an educator and builder from Oklahoma who spends his time making things work: classrooms by day, code by night. I like systems that are deep enough to be interesting and polished enough that other people actually want to use them.

    Most of my work lives in the Minecraft ecosystem — Java plugins on Paper, Fabric mods, Skript systems, and custom resource packs with hand-built 3D models. Outside of that I build games in Godot and Unity, and web apps that run entirely on your own machine.

    I care about the details: a weapon that feels different, a GUI that reads clearly, a build that actually compiles and runs.
